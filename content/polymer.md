# 聚合物构建：从 SMILES 到有拓扑的链

`structure.polymer` 模块用**重复单元 SMILES** 造聚合物。它不是“预设几种常见塑料”，而是任意写了两个 `*` 连接点的重复单元。

## 1. 参数怎么填

| 参数 | 含义 |
| --- | --- |
| 重复单元 SMILES | 必须正好两个 `*`，例如 `*CC*`（聚乙烯）、`*C(=O)c1ccc(cc1)C(=O)O*`（PET 类聚酯片段） |
| 链数 / 单体数 | 多少条链、每条链多少重复单元 |
| 目标密度 | g/cm³（初始结构的目标） |
| 最小原子间距 | Å，**必须 ≥ 2.0**（LJ 核心重叠会让动力学立刻发散） |
| 随机种子 | 复现同一初始结构 |

## 2. 它内部做了什么

1. RDKit 解析重复单元，去掉两个 `*`，记住它们连的原子（链端）；
2. 复制 N 份单体，把第 i 份的“头”与第 i+1 份的“尾”接上单键 → 一条链；
3. `Chem.AddHs` 补氢，ETKDG 生成 3D 构象，MMFF 快速优化；
4. 按密度和目标链长算盒子；**逐条链**随机旋转 + 平移，检查周期最小像距离；
5. 输出带显式 `bonds / angles / dihedrals` 与 `molecule_ids` 的结构。

## 3. 为什么初始密度往往低于你填的值

一条 12 单体的聚乙烯链伸展半径就有 ~10 Å。硬把它塞进 20 Å 的盒子里，必然出现原子重叠。平台的处理是：

- 盒子取 `max(密度对应体积, 2.1 × 链回转半径)`；
- 如果摆不下，按 12% 逐步放大盒子重试（最多 6 次）；
- 实际密度写在结构 provenance 里（`actual_density_g_cm3`）。

所以正确流程是 **低密度建结构 → NPT 压缩**，而不是“一步到 0.9 g/cm³”。

> [!WARNING]
> 平台会拒绝 `min_distance < 2.0 Å` 的请求。C-C 的 σ≈3.4 Å，1.2 Å 的重叠对应 ~10⁶ eV 的能量，跑两步就会“bond atom missing”。

## 4. 接键合力场

结构自带拓扑，所以 `forcefield.library` 的「键合项」不会再跑键感知，而是**给已有键分配类型和系数**（DREIDING 风格的谐振子：`K` 按键级取 700/1050/1400/2100 kcal/mol/Å²，`r0` 取该类型键长的平均值；角度 `K=100 kcal/mol/rad²`，`θ0` 取平均值；二面角默认 0 势垒，只保留连接性）。

> [!IMPORTANT]
> 这套键合参数是**几何派生的 MVP**，不是某个聚合物的文献力场。做定量力学/热学前，请用 `forcefield.custom` 或系数字符串覆盖成文献值（OPLS、PCFF、COMPASS…）。

## 5. 怎么判断建得对不对

- **不变量**：线性链的键数 = 原子数 − 链数；键、角、二面角都不重复；
- **几何**：所有键长应在 1.0–1.6 Å（C-H ~1.09，C-C ~1.53）；
- **周期**：不要把单条链拆到盒子两边（平台不会 wrap 链内原子，就是为了避免跨边界键）；
- **动力学**：先跑 1 ps NVE 看能量是否守恒，再上 NPT 压缩。

> [!CHEMISTRY]
> 聚合物和 MOF 的关键差别是**拓扑自由度**：MOF 是刚性骨架（GCMC 常固定框架），聚合物链会缠结、重排，所以需要 NPT + 足够长的弛豫。看到密度还在单调上升，说明还没平衡，不要急着报数。
